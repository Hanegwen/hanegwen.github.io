# hanegwen.github.io

The public static website for Michael Morrone's iOS apps, served by GitHub Pages at
https://hanegwen.github.io.

This repository contains only the website: the app list, privacy policies and `app-ads.txt`.
The app source code lives in a separate private repository and is not part of this site.

Plain HTML and inline CSS; no build step. `.nojekyll` tells GitHub Pages to serve the files as-is.
